
# Sales Performance Dashboard

## Project Overview
An interactive sales dashboard built using
Microsoft Power BI to explore online retail
transactions and sales performance.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Excel

## Dashboard Features
- Total revenue KPI
- Unique invoice count
- Top 10 products by revenue
- Monthly sales trends
- Top 10 countries by revenue
- Country slicer for interactive filtering

## Dataset
UCI Online Retail Dataset:
https://archive.ics.uci.edu/dataset/352/online+retail

## Analysis Process
1. Imported the retail dataset.
2. Created a revenue calculation.
3. Built KPI cards and charts.
4. Added a country slicer.
5. Arranged the visuals into a dashboard.
